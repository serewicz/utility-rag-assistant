This is a plain-language summary written for this demo, not the official standard text.

CIP-007 covers ports and services, security patch management, malicious code prevention, security event monitoring, and system access control.

For patch management, the entity must evaluate security patches for applicability at least once every 35 calendar days. Within 35 days of the evaluation, it must apply the patch, create a dated mitigation plan, or revise an existing plan.

Security event logs must be retained for at least the last 90 consecutive calendar days. Unsuccessful login attempts must be limited or alerted on.
