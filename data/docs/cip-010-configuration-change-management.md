This is a plain-language summary written for this demo, not the official standard text.

CIP-010 requires a documented baseline configuration for each BES Cyber System, including operating system, installed software, open logical ports, and applied security patches.

Changes that deviate from the baseline must be authorized and documented, and the baseline updated within 30 calendar days of completing the change. For high impact systems, the entity must monitor for unauthorized baseline changes at least once every 35 calendar days.

A vulnerability assessment is required at least once every 15 calendar months.
